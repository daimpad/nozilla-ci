# Font-Awesome-Free-Katalog · nozilla-Nachbau

**Gute digitale Dienste.**

Vollständige Liste aller frei verfügbaren Font-Awesome-Icons (Version 6.7.2) mit Name, Bedeutung und Nachbau-Status im nozilla CI.

## Bestand

| Kennzahl | Wert |
|---|---|
| Freie Icons gesamt (Stilvarianten) | **2060** |
| Davon eindeutige Namen | **1895** |
| Stil `solid` | 1402 |
| Stil `regular` (Outline-Variante, keine eigenen Namen) | 163 |
| Stil `brands` (fremde Markenlogos) | 495 |
| Nachbau-Universum (frei, ohne Markenlogos) | **1400** |
| Im nozilla CI nachgebaut | **462** |
| Kategorien | 68 |

## Was nicht nachgebaut wird

Die 495 `brands`-Icons sind Logos fremder Unternehmen und Produkte. Sie sind markenrechtlich geschützt — ein Nachbau im nozilla-Stil wäre eine unzulässige Veränderung fremder Marken und obendrein unbrauchbar, weil ein Logo nur in seiner Originalform wiedererkannt wird. Sie stehen in diesem Katalog, werden aber nicht gezeichnet.

## Nachbau — Dialekt A

Jedes Icon: SVG, 64 × 64 Grundraster, 4 px Strichstärke, `stroke-linecap="square"`, `stroke-linejoin="miter"`, Tinte-Schwarz `#000`, Signal-Grün `#00FF9C` nur als Akzent. Keine Radien, keine Verläufe, keine Filter.

Dateien liegen in [`project/assets/icons/`](./project/assets/icons/) als `nz-<name>.svg`. Galerie: [`icons.html`](./icons.html).

---

## So liest sich der Katalog

| Spalte | Inhalt |
|---|---|
| **Name** | Der Font-Awesome-Name. Er ist der Schlüssel — die nozilla-Datei heißt `nz-<name>.svg`. |
| **Bedeutung** | Wofür das Icon steht. Nachgebaute Icons tragen die nozilla-Lesart auf Deutsch, alle übrigen das *englische Font-Awesome-Label in Kursiv*. |
| **Stil** | In welchen freien Font-Awesome-Stilen der Name existiert. |
| **nozilla** | ✓ mit Link auf die SVG-Datei, wenn nachgebaut. Sonst –. |

Ein Icon steht in jeder Kategorie, der Font Awesome es zuordnet — Mehrfachnennungen sind daher normal.
